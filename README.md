# Dashboard Meteorológico

Aplicación web interactiva desarrollada con **React** y el empaquetador **Vite** para la gestión y visualización de condiciones meteorológicas en tiempo real. Este proyecto implementa una arquitectura desacoplada donde el frontend no consume directamente las APIs públicas de terceros; en su lugar, se apoya en un proceso de ingesta en Node.js que normaliza y persiste la información en **Supabase** bajo un esquema dedicado.

---

## Características Principales

* **Autenticación Externa (OAuth con GitHub):** Control de acceso seguro gestionado por **Supabase Auth** vinculado a una aplicación OAuth en GitHub, permitiendo el ingreso seguro incluso a usuarios con correo privado (`Allow users without an email`).

* **Arquitectura Desacoplada:** El cliente web consume de forma exclusiva la base de datos de Supabase, respetando las restricciones de seguridad y persistencia antes de visualización.

* **Ingesta Automatizada con Upsert:** Proceso en Node.js que consulta **OpenWeatherMap**, transforma unidades (velocidad de viento a km/h) y aplica operaciones `upsert()` tomando como conflicto el nombre de la ciudad para evitar duplicidades.

* **Diseño en Dos Columnas:**

  * **Tarjeta Destacada:** Presentación visual de la ciudad principal (**Celaya**) con temperatura en °C, sensación térmica, humedad, viento, descripción, icono de contraste e indicador de última actualización en hora local mexicana (12h).

  * **Catálogo de Ciudades Disponibles:** Cuadrícula con contenedor de desplazamiento vertical independiente para explorar múltiples localidades sin generar scroll global en la ventana.

* **Búsqueda Reactiva en Tiempo Real:** Filtrado instantáneo en memoria sobre el listado de ciudades por nombre o código de país sin peticiones HTTP redundantes.
* **Actualización en Caliente:** Botón interactivo en la cabecera que consulta el clima actual de la ciudad seleccionada y actualiza su registro directamente en Supabase reflejándolo de inmediato en la UI.

## Estructura de la Base de Datos (Supabase)

La base de datos PostgreSQL en Supabase organiza los datos en un esquema aislado para esta práctica:

* **Esquema:** `clima`
* **Tabla:** `ciudades`

```sql
CREATE SCHEMA IF NOT EXISTS clima;

CREATE TABLE IF NOT EXISTS clima.ciudades (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    ciudad TEXT NOT NULL UNIQUE,
    pais TEXT NOT NULL,
    temperatura NUMERIC(5, 2) NOT NULL,
    sensacion_termica NUMERIC(5, 2),
    humedad INT,
    viento_velocidad NUMERIC(5, 2),
    descripcion TEXT,
    icono TEXT,
    actualizado_en TIMESTAMPTZ DEFAULT NOW()
);
```

## Guía de Instalación y Ejecución Local

### 1. Clonar el repositorio
```bash
git clone https://github.com/jesustovaarr/practica-dashboard-clima.git
cd practica-dashboard-clima
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Configurar variables de entorno
Crea un archivo `.env` en la raíz del proyecto a partir de la plantilla:

```bash
cp .env.example .env
```

Define tus credenciales en el archivo `.env`:

```env
# Variables accesibles desde React (Frontend)
VITE_SUPABASE_URL=https://tu-proyecto.supabase.co
VITE_SUPABASE_ANON_KEY=tu-anon-key-de-supabase
VITE_OPENWEATHER_API_KEY=tu-api-key-de-openweather

# Variables para el script de ingesta (Node.js)
OPENWEATHER_API_KEY=tu-api-key-de-openweather
```

### 4. Ejecutar la ingesta inicial de datos
Carga las ciudades iniciales a la tabla `clima.ciudades` de Supabase:

```bash
node syncWeather.js
```

### 5. Iniciar el servidor de desarrollo
```bash
npm run dev
```

Abre tu navegador en la dirección indicada por la consola (habitualmente `http://localhost:5173`).
